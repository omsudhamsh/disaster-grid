# Accessibility Statement

## Our Commitment

Disaster Grid aims to provide an accessible web interface for users with different abilities and assistive technologies.

The project uses a React-based interface and interactive elements such as maps, dashboards, filters, tables, forms, and data visualizations.

## Accessibility Goals

We aim to:

- Use semantic HTML where practical.
- Provide keyboard-accessible controls.
- Maintain visible focus states.
- Provide meaningful labels for forms and interactive controls.
- Use sufficient text contrast.
- Avoid relying on color alone to communicate critical information.
- Provide useful alternative text for meaningful images.
- Make error and status messages understandable.
- Keep navigation consistent across pages.

## Known Limitations

Because Disaster Grid is an evolving academic project, some accessibility limitations may remain, particularly around:

- Interactive map controls and map-based visualizations.
- Complex data visualizations and heat maps.
- Dynamic live-data updates.
- Third-party authentication and embedded services.

## Reporting an Accessibility Barrier

If you encounter an accessibility barrier, please open a GitHub issue with the **Accessibility** template when the report does not contain sensitive information.

Please include:

- The page or feature affected.
- What you expected to happen.
- What happened instead.
- Browser and operating system.
- Assistive technology, if applicable.
- Steps to reproduce.
- Screenshots or recordings, if useful and safe to share.

Do not include passwords, API keys, personal information, or other sensitive data.

## Ongoing Improvement

Accessibility feedback is welcome and will be considered as the project evolves.
